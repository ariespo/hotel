# 立绘 V2 视觉验收门槛

## 为什么旧测试会漏检

旧测试只证明素材文件存在、画布尺寸相同、运行时只绘制一张发型。它没有证明不同文件来自同一人体母版，也没有检查眼窝、耳根、发际线、下巴和脖颈是否相互对齐。因此即使测试全绿，独立生成的脸、眼、发仍可能拼成错误人物。

## 强制门槛

1. 独立位图层默认关闭，`RASTER_PARTS_VALIDATED` 必须保持 `false`。
2. 新部件必须从同一张 384×512 裸头母版派生，禁止把各自独立生成的完整头像直接当作图层。
3. 打开 `portrait-v2-lab.html`，逐格检查完整预设、全部脸型、眼型、刘海和发型。
4. 每张必须以 3:4 原始比例检查，不得只看整页缩略截图。
5. 验收项：双眼中心、耳根连接、鼻嘴归属、发际线、遮脸范围、下巴—脖颈连接、肤色/瞳色/发色换色、配饰前后层级。
6. 任何一格出现悬空、重复器官、断颈、错误遮挡或画风突变，整批素材不得进入运行时。
7. 自动测试只负责拦截结构错误；最终开关必须基于人工组合表验收，不能由“测试通过”代替。

## 发布验收

- 运行语法检查与完整回归测试。
- 在发布环境打开组合验收表并保留全页截图。
- 再进入真实捏脸页面，至少复检五个预设和随机外观。
- 浏览器控制台必须无资源加载错误。
