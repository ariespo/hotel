### 短描述

《多元便携旅店》是一款像素风旅店建造经营游戏。自由扩建漂泊于星海中的旅店，规划房间与家具动线，招募拥有不同性格和关系的员工，接待来自不同位面的客人。可选接入 OpenAI 格式接口，让员工对话、事件结果与每日经营记录变成属于你的连续故事。

## 宇宙很大，但今晚总要有一盏灯为谁亮着

位面门在星空下开启，来自不同世界的旅人走进你的店。他们有人只想吃一顿热饭，有人准备喝到打烊，也有人需要一张能安心睡到天亮的床。

而你，是这间旅店的店主。

从一间餐厅、一座厨房和几间客房开始，亲手决定旅店的每一面墙、每一扇门、每一张桌椅，以及每一个来到这里的人会经历怎样的一晚。

### 【动图 1：选择房间蓝图 → 旋转 → 贴边放下 → 自动生成居中门洞】

## 像拼积木一样，造一间真正能运转的旅店

房间不是静态背景，而是经营系统的一部分。餐饮间、厨房、储藏室、客房、酒吧、温泉、星象台、放映厅、炼金房……不同空间会带来不同服务，也会改变客人和员工的行动路线。

- 自由摆放、旋转和重新移动整间房
- 根据相邻墙面的有效空间自动生成门洞
- 移动房间时同步搬迁家具、污渍与房内角色
- 升级房间品质、改变装修风格，逐步解锁更高级的家具成长线
- 用走廊整理动线，避免客人与员工堵在狭窄路口

你设计的不只是“好看的平面图”，还是一套需要经得起晚高峰考验的空间系统。

**截图字幕：** 房间、门洞与动线，由你亲手规划。

### 【动图 2：选中具体房间 → 家具列表自动过滤 → 放置桌椅/灶台 → R 旋转使用面】

## 每件家具都不只是装饰

桌椅需要正确朝向，灶台、备餐台、出餐口和储物架要组成顺畅的生产线；设备的使用面必须能够到达，员工才能真正开始工作。

家具会影响容量、效率、舒适度、氛围和客人体验。你可以随时移动或旋转已经放下的家具，也可以沿着基础、装饰与招牌三条成长线提升品质。

想做一间高效的小店，还是一座值得专程跨越位面前来的奢华旅店？空间有限，取舍永远存在。

**截图字幕：** 好看的布置，也必须真的好用。

### 【动图 3：开门营业 → 客人进店 → 员工迎宾、点单、取料、烹饪、上菜 → 工作队列实时变化】

## 开门之后，每个人都会自己动起来

员工会根据岗位、负责区域、能力、性格和抢单优先级自动认领工作：

**迎宾 → 安排座位 → 点单 → 取料 → 备餐 → 烹饪 / 调酒 → 出餐 → 上菜 → 收台 → 清洁**

你不需要逐个下达重复命令，但必须为他们创造能够顺利工作的条件。工作队列会告诉你任务是“待领取”“前往中”还是“处理中”；卫生与拥堵热图则会暴露更深层的布局问题。

是岗位没人负责？员工已经忙不过来？还是厨房离储藏室实在太远？每次营业，都会检验你的规划。

**截图字幕：** 看得见的员工，跑得起来的经营链。

### 【截图 4：员工详情页 / 两枚性格标签 / 好感度 / 店内关系 / 自动优先级】

## 招来的不是数值卡，而是一群要朝夕相处的人

员工拥有年龄、种族、外观、技能、性格、背景与彼此之间的关系。勤恳的人更耐劳，完美主义者追求更好的出品却需要更多时间；话痨会在打烊后主动串门，独来独往的人则未必喜欢热闹。

性格之间既有相性，也会发生对冲。共同工作、休息和闲聊，会让同事成为朋友，也可能积累矛盾。

- 根据属性与性格自动规划工作优先级
- 自由调整岗位、负责房间与抢单顺序
- 一名员工对应一间休息室卧室
- 点击性格标签查看说明、相性与冲突
- 为每名角色换装，或生成符合现有属性的人物背景

作为店主，你不领取工资——但每个经营决定，最后都要由你承担。

**截图字幕：** 技能决定他们能做什么，性格决定他们会成为谁。

### 【截图 5：客人页签同时出现用餐、娱乐、住宿客；显示耐心和当前状态】

## 万界来客，各有各的目的

不同客人带着不同预算、口味和来意走进旅店。他们可能想吃饭、喝酒、泡温泉、观星、看一场放映，也可能在客房住上一夜。

耐心会随着等待不断下降。没人迎宾、没有座位、菜迟迟不上，或环境太脏，都会成为差评和流失的原因。反过来，舒适的空间、恰到好处的服务和精彩设施，也会让他们愿意花更多时间与界币。

住宿客会在客房的床上真正躺下，第二天开门后再统一结账离店。夜深以后，旅店仍会留下属于打烊时刻的故事。

**截图字幕：** 每位客人都有目的、耐心与正在经历的旅程。

### 【动图 6：菜单上下架 → 调整配方 → 指派厨师 → 研发成功并命名新菜】

## 经营你的菜单，也创造自己的招牌菜

菜品会真实消耗库存。售价越高，对厨艺、调酒、设施和食材的要求也越高；无法稳定制作的菜，即使写在菜单上，也只会制造更多等待。

在收盘规划期走进厨房，你还可以研发新菜：调整配方用量、组合口味与趣味效果、指派合适的厨师，并为最后的成品命名。

一份菜单，就是你对效率、成本、售价与口碑做出的选择。

**截图字幕：** 从库存到配方，做出只属于这家旅店的味道。

### 【截图 7：六项评分明细 + 收入/工资/维护/补货 + 员工工作统计】

## 每一天都有清楚的账，也有值得记住的事

营业收入会在客人结账时实时入账；日结只扣除员工工资、房间与家具维护，以及自动补货成本，不会重复计算收入。

每天结束后，你可以查看：

- 菜品与设施收入、工资、维护、补货和净收益
- 接待与流失客人数，以及具体流失原因
- 品质、等待、服务、卫生、舒适与观赏六项评分
- 每名员工完成了什么工作、成长了哪些技能
- 事件选择造成的真实数值变化

找到短板，重新规划，然后再开一天。

**截图字幕：** 不只有总分——每一笔钱、每一份工作都有来处。

### 【动图 8：员工连续聊天 → 日结小说章节 → 事件自定义输入与结构化选项】

## 可选 AI：让经营记录变成连续发生的故事

游戏可以完全离线游玩全部经营内容。玩家也可以自行配置兼容 OpenAI Chat Completions 格式的接口与模型，为叙事部分增加更多变化。

接入后可用于：

- 与员工或客人进行连续对话
- 根据角色属性生成背景故事
- 为自创菜品提供命名灵感
- 演绎事件选择后的剧情结果
- 把当天客流、盈亏、数值变化和员工工作写成日结小说章节
- 在符合条件的打烊互动中，以选项或自定义输入继续推进剧情

角色回复会参考店主身份与背景、双方好感、当前状态、玩家刚说的话，以及此前的对话历史。AI 负责叙事，经营系统负责检定与数值——模型不能凭一句话改写你的账本。

> AI 功能完全可选，需要玩家自行提供兼容接口、密钥与模型；密钥仅保存在当前浏览器。没有配置 AI 时，基础经营、事件与互动仍可正常进行。

**截图字幕：** 让今天的账本，成为明天仍会被记得的故事。

你最终留下的，不只是一座效率越来越高的建筑。

还有一群曾在这里工作、争吵、和好、成长的人；以及无数在星海深处推开门，短暂停留过的旅人。

## 商店页合规与真实性备注

- “AI”必须始终标注为可选功能，并说明需要玩家自行配置兼容接口。
- 不使用“无限剧情”“完全自由”“每个角色真正拥有意识”等无法验证或容易误导的表述。
- 夜间互动的画面与文字应保持含蓄，明确所有相关角色均为成年人，并强调自愿、可拒绝与随时退出。
- 所有宣传图优先使用实机 UI 与实际可达到的经营状态；标题背景图只适合作为胶囊图或氛围过场，不应冒充实机截图。
