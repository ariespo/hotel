# Candidate C 正式母版三阶段验证

本目录按同一目标逐步编辑，不是三张分别生成的独立部件。当前仍是全图验证稿，用于确认结构与画风；尚未提取透明运行时图层。

## 01 · 标准裸头母版

`01-bare-head-master.png`

- 移除全部头发、眉毛、眼球、虹膜与睫毛。
- 重建完整头骨、额头和太阳穴。
- 保留浅眼窝、眼睑定位线、双耳、鼻嘴、脸缘、下巴、脖颈、肩线和服装。
- 头骨小于成品发型外轮廓，预留合理发量空间。

## 02 · 第一套正式眼睛

`02-formal-eyes-validation.png`

- 只在 01 的眼窝和眉区添加窄眼与匹配眉毛。
- 低饱和冰灰蓝虹膜、小瞳孔、细上眼线、稀疏下睫毛和眼下排线。
- 双眼等高、虹膜等大、视线正中；鼻嘴、脸缘、耳朵与头骨保持不变。

## 03 · 第一套正式头发与完整角色

`03-complete-character-validation.png`

- 只在 02 上增加近黑靛蓝中分长发。
- 后发位于头颈和肩后；贴头主发块遵循 01 的头骨；少量游丝留在脸外。
- 双耳、眉眼、鼻嘴、下巴和脖颈完整可见。
- 作为第一套稳定基础长发；更强烈的断裂发束和夸张轮廓留给后续风格发型。

## 当前结论

- 三阶段保持统一正面结构，没有把独立生成的脸、眼、发直接叠加。
- 画风为低饱和、冷峻、细线与硬边块面的编辑插画方向。
- 在用户确认完整角色画风前，`RASTER_PARTS_VALIDATED` 继续保持 `false`，不接入游戏。
- 确认后下一步是从同一三阶段全图通过差分与人工修边提取 `faceBase`、`eyes`、`hairBack`、`hairFront`，并在透明画布上重新合成回 03 做对位验证。
