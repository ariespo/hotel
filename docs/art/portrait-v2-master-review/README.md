# 正式立绘母版评审

## Candidate A

- 文件：`standard-master-candidate-a.png`
- 原始尺寸：1086×1448，严格 3:4。
- 用途：确认最终画风与标准正面人体母版，不直接作为运行时拆分部件。
- 生成方式：内置 ImageGen；参考 `portrait-v2-style-reference.png` 与用户确认的清透现代二次元方向。

### 已通过的结构检查

- 正面、无倾斜、双眼等高，瞳孔与虹膜方向一致。
- 双耳完整且耳根高度一致，没有悬空。
- 下巴、脖颈、肩线连接清楚，适合之后建立统一锚点。
- 发际线遵循头骨，头发未遮挡眉眼、鼻嘴、下巴和脖颈。
- 画风达到清透眼睛、细睫毛、自然鼻唇、柔和面部体积和成束冷色发丝高光。

### 正式拆分前仍需处理

- 先从 Candidate A 派生无头发、无服装的裸头母版，不能直接把本图裁成脸/眼/发三个独立部件。
- 裸头母版需保留完整头骨、耳朵、脸、脖颈和肩线；鼻子与嘴巴随脸型派生。
- 第一轮仅制作 1 个裸头、1 个眼型、1 套后发和 1 套前发，合成回 Candidate A 做像素级对位检查。
- 通过后再扩展其他脸型和发型，且保持 `RASTER_PARTS_VALIDATED=false`，直到组合表全部验收完成。

### 生成提示词摘要

正面、对称、上胸像、现代精致二次元赛璐璐、柔和面部体积、清透蓝灰虹膜、细睫毛、自然鼻唇、黑发冷蓝紫成束高光；中分并露出耳根、脸缘和脖颈；禁止歪头、三分之四角度、遮挡五官、悬空耳朵、断颈和独立贴片感。

## Candidate C · 推荐风格化方向

- 文件：`standard-master-candidate-c-stylized.png`
- 原始尺寸：1086×1448，严格 3:4。
- 用途：替代 Candidate A 成为当前推荐的正式画风候选；仍不直接作为运行时拆分部件。

### 相对 Candidate A 的调整

- 更长、更尖锐的面部比例与块面阴影，减少标准商业二次元的圆润抛光感。
- 窄眼、较小虹膜、克制而疏离的表情，强化人物辨识度。
- 超细断续线、局部排线、低饱和平涂和硬边阴影共同形成编辑插画感。
- 头发改为大束刀锋形结构、稀疏冷紫反光块和脸外游丝，不再使用光滑头盔式高光。
- 服装采用深青黑大色块、锐角高领和氧化银星门扣，避免常见金边旗袍模板。
- 深青黑背景强化浅肤色与发丝外轮廓，同时保留正面模块化要求。

### 结构检查

- 正面、无歪头；双眼、耳根和肩线保持水平。
- 双耳、眉眼、鼻嘴、下巴和脖颈全部可见，没有被前发遮挡。
- 下巴与脖颈居中连接，发际线遵循头骨，适合继续派生裸头母版。
- 脸外游丝属于风格装饰；正式拆层时必须归入独立前景发丝层，不得混进脸型底图。
