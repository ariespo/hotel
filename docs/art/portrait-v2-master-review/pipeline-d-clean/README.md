# Pipeline D · 干净高细节模块母版

本管线用于确认“低噪点、无跨模块投影”不等于“简化五官”。三张验证图统一为 `1085×1450`，画布、头骨与五官坐标完全一致；当前仍是同源全图验证稿，尚未提取透明部件。

## 01 · 干净裸头母版

`01-clean-bare-head-master.png`

- 清除纸纹、颗粒、排线、脏灰与细碎笔刷痕迹。
- 保留稳定肤色、脸型、鼻口、耳朵与颈部结构。
- 眼区不预烘焙眼窝、眼睑或眼下阴影，避免限制后续眼型。

## 02 · 无皮肤阴影的高细节正式眼型

`02-clean-detailed-eyes.png`

- 眼位继承已确认的风格候选图：锁定眼裂高度、眼距、外眼角角度和左右基准线，不从裸头重新猜测。
- 完整保留属于眼睛自身的上下眼线粗细变化、成组睫毛、眼白、湿润线、虹膜外圈和内圈、虹膜纹理、瞳孔、多点高光与眉毛细节。
- 仅移除属于皮肤的眼窝、眼睑渐变、眼下阴影和肤色染色；不得把“无面部阴影”误做成“简化眼睛”。
- 眼色换色只处理虹膜通道，不影响线稿、瞳孔、纹理与高光。

## 03 · 无跨模块投影的正式发型合成

`03-clean-detailed-complete.png`

- 中分深靛黑长发，完整露出眉毛、眼睛、耳朵和面部轮廓。
- 头发采用基础色、少量较暗分界色和一档冷色高光，保留清晰的大束结构与设计感。
- 发型不得向额头、太阳穴、眼睛、脸颊、耳朵、脖颈或服装投射阴影。
- 禁止渐变、颗粒、排线、脏污纹理和逐根发丝噪点。

## 生产规则

- 眼型模块不得包含任何皮肤阴影像素，但必须保留虹膜纹理、多点高光、上下眼线和睫毛层次。
- 发型模块不得包含任何落在其他模块上的投影像素。
- 每一个新眼型都必须套回同一母版，以眼位基准线和关键点检查定位，不允许凭清空后的眼眶重新估计。
- 后续提取透明层前，必须再次确认三张图的画布、头骨、五官与肩线坐标完全相同。
