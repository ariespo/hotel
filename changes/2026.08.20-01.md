# 2026.08.20-01 · 中期性能与员工操作修复

## 功能

- 员工与店主姓名旁使用独立的小号字体标注“男 / 女”，并以不同颜色辅助识别。
- 自定义职责优先级支持营业中即时调整；关闭员工当前职责时会释放任务并重新规划。
- 解雇确认不再因为正在营业而失效，营业中解雇会先释放该员工的当前任务。
- 建立全局版本记录流程：每次更新维护独立 Markdown 说明和总更新日志，推送、部署及发布包构建前强制校验；README 同步提供创建与校验命令。

## 修复

- 店主创建页的能力词条改为非交互标签，避免点击后打开通用人物弹窗并关闭创建界面。
- AI 游戏请求启用 JSON 输出模式，并兼容字符串、分段内容及对象形式的响应；空响应会返回可操作的错误说明。
- 修复自定义职责按钮在营业期间点击无反馈的问题，并增加即时状态提示。
- 去除解雇员工和调岗时“最后一名前台”的硬性阻断，前台缺口继续由经营提示和任务系统处理。
- 在 100% 缩放的窄桌面窗口隐藏次要身份信息、压缩经济区并提前收纳次要按钮，避免顶栏右侧被遮挡。

## 性能与兼容性

- 员工任务规划增加短周期节流，仅在存在可分配空闲员工时扫描完整任务集合，减少中后期每帧重复遍历。
- 客人与订单渲染改用预先建立的 ID 映射，移除角色和桌面物品循环中的重复 `find` / `filter` 扫描。
- 客人离场后按外观引用释放不再使用的 PIXI 纹理及其 GPU 资源，替代只清空缓存映射造成的显存持续增长。
- 顶栏兼容 1366×768、100% 缩放的桌面窗口，同时保留 1920×1080 布局。
